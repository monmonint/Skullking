# Installation — Skull King Score (non officiel)

Compte-points hors ligne pour Skull King (règles Halcyon / Grandpa Beck’s 2022).
Aucune affiliation avec ScoreNow, Grand Prix Games ou Grandpa Beck’s Games.

## Installer l’APK (Android 64 bits)

1. Copiez `artifacts/skull-king-scorekeeper.apk` (ou `skull-king-scorekeeper-arm64-release.apk`) sur le téléphone.
2. Ouvrez le fichier → autorisez **Sources inconnues** si demandé.
3. Installez et lancez **Skull King Score**.

APK **release arm64-v8a** uniquement (téléphones modernes). Non destiné au Play Store.

## Fonctionnalités

### Modes de cartes (journal de bord 2022)
| Mode | Séquence |
|------|----------|
| Standard | 1→10 |
| Pas d’impair | 2,2,4,4,6,6,8,8,10,10 |
| Attaque éclair (Blitz) | 5×5 |
| Tir de barrage | 10×10 |
| Tourbillon | 9,9,7,7,5,5,3,3,1,1 |
| Heure du dodo | 1 |
| Prêt au combat | 6→10 |
| Personnalisé | liste libre |

### Score classique
- Exact (≠0) : +20 × plis  
- Raté : −10 × écart (pas de bonus)  
- Mise 0 : ±10 × cartes de la manche  
- Bonus si exact : 14 couleur +10, 14 noir +20, sirène←pirate +20, pirate←SK +30, SK←sirène +40  

### Extensions (toggles)
- **Kraken** : pli détruit → compteur « plis annulés »  
- **Baleine blanche** : plus haut numéro gagne ; pli annulé si que des spéciaux ; si Kraken+Baleine, la 2ᵉ carte prime  
- **Harry le Géant** : phase d’ajustement mise ±1  
- **Butin** : +20 par alliance réussie (les deux exacts)  
- **Rascal le Flambeur** : pari 0/10/20  
- **Tigresse / Scary Mary** : notes dans le flux bonus (pirate si jouées en pirate)

### Autre
- 2–8 joueurs, reprise des noms, historique local, revanche, stats « mises exactes »
- Hors ligne, UI française, thème sombre

## Non inclus
- Système de score alternatif **Rascal / Boulet de canon** (méthode complète) — voir README  
- Pouvoirs Rosie / Will / Juanita (effet de table, pas de score)  
- Simulation de plis (l’app compte seulement)

## Désinstaller
Paramètres → Applications → Skull King Score → Désinstaller.
